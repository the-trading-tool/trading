Trading-Agent run_agent.py

Automatisierter Trading-Agent für Paper- und Live-Trading. Wertet Kauf-/Verkaufssignale aus asset_simulation_.db aus und sendet Broker-Orders.

Aufruf

python run_agent.py [Optionen]

Parameter

ParameterStandardBedeutung
--executeNeinOrders tatsächlich absenden (ohne diesen Flag: Dry-Run)
--useradminBenutzer-Kontext (Multi-User-Setup)
--regionalleNur Signale eines bestimmten Index prüfen (z. B. GDAXI)
--buy-offset0.0Prozentualer Aufschlag auf den Kaufpreis (Limit-Order-Puffer)
--force-buyNeinKauf auch ohne frisches Signal erzwingen
--notifyNeinNach dem Lauf Pushover-Benachrichtigung senden
--modepaperpaper oder live
--brokeralpacaBroker-Backend: alpaca · ibkr

Exit-Codes

CodeBedeutung
0Kein Signal, alles OK
1Kauf- oder Verkaufsorder wurde ausgelöst
2Fehler (Broker nicht erreichbar, Datenbankfehler …)

Empfohlener Scheduler-Eintrag

# Alle 15 Minuten während der Handelszeiten:
python run_agent.py --notify --mode paper
Mit --execute --mode live werden echte Orders beim Broker aufgegeben. Ausreichend testen im Paper-Modus, bevor Live-Trading aktiviert wird.
Die Batch-Datei run_agent.bat ist ein Windows-Wrapper für denselben Aufruf.
