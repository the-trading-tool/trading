Load asset info get_asset_info.py

Fetches master and fundamental data for all known tickers from Yahoo Finance and stores it in asset_info.db. Only needs to run occasionally, since fundamentals rarely change.

Call

python get_asset_info.py

Without parameters the complete ticker list from yf_tickers.db is processed (re-imports All_Assets.xlsx if present).

Parameters (ticker selection & speed)

ParameterEffect
/group:ETPLoad master data only for members of the named group(s), several comma-separated (/group:METALS,COMMODITIES). Case-insensitive. This lets you top up, say, only the new ETPs instead of all ~8000 tickers.
/worker:NN parallel info downloads (default 1 = sequential). The .info queries are separate requests per ticker → thread-safe. Recommendation 2–4 (Yahoo rate limit).
python get_asset_info.py /group:ETP /worker:4
Pipeline note – when do imported assets become visible?
For tickers to appear in the "Select asset by market" → "Select company" dropdown and in the full-text search, they must be in asset_info.db – which is exactly what this script writes. The market itself (e.g. ETP) appears already after get_asset_data.py (from the indices table in yf_tickers.db); the company list however stays empty ("No options to select") until get_asset_info.py has loaded the master data (the dropdown uses an INNER JOIN on asset_info).
Full-text search: This script automatically rebuilds the FTS search table (asset_info_fts) at the end – so new tickers are findable by name search right after the run. The manual admin button "Update index" remains as a fallback but is no longer needed after this script.

When to run?

  • After the first setup (after seed_db.py)
  • After adding new tickers in the admin panel
  • After importing a new group via get_asset_data.py (e.g. ETP) – targeted with /group:NAME, so the new tickers appear in the "Select company" dropdown and in the search
  • Quarterly for updated fundamentals
Existing entries are updated (upsert). The fetch runs with pauses between requests to respect Yahoo rate limits.
