Start the application launcher.py · asset_analyzer.py

The Trading App is a Streamlit web application that runs locally in the browser. There are two ways to start it.

Way 1 – Directly via the command line (recommended for development)

cd Trading
streamlit run asset_analyzer.py

The browser opens automatically at http://localhost:8080.

Way 2 – Windows launcher (for end users)

python launcher.py

The launcher:

  1. Detects the Python installation automatically
  2. Starts streamlit run asset_analyzer.py in the background
  3. Waits until the server is ready
  4. Opens the browser automatically
  5. Optionally shows a system-tray icon

Compile as a Windows EXE

pyinstaller --onefile launcher.py

The generated launcher.exe can be started directly by double-click, without any Python knowledge.

URL parameters

ParameterExampleEffect
symbol/?symbol=AAPLOpen Asset Details for this ticker directly
rotation/?rotation=trueOpen the sector-rotation dashboard
The port and other Streamlit settings can be adjusted in .streamlit/config.toml (e.g. server.port = 8080).
