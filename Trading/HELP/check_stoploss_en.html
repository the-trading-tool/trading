Stop-loss check check_stoploss.py

Monitors all open positions and checks whether the price has fallen below the ATR trailing stop. Can automatically trigger a sell order when breached.

ATR trailing-stop concept

Stop-loss level = highest price since purchase (HWM) minus N × ATR

  • HWM – Highest Water Mark (highest price reached since entry)
  • ATR – Average True Range (a measure of the average daily volatility)
  • N – configurable multiplier (default: 2.0)

The stop level is adjusted upward daily when the price rises – never downward.

Call

The batch file check_stoploss.bat is a Windows wrapper. For intraday monitoring, run every 15–30 minutes via the scheduler.
With --execute --mode live real sell orders are placed. Test without --execute first.
