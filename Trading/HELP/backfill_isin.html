ISIN-Befüllung backfill_isin.py

Ergänzt fehlende ISINs in der Ticker-Datenbank (yf_tickers.db) durch Abfrage von Yahoo Finance. Nützlich nach dem Import neuer Ticker ohne ISIN-Angabe.

Aufruf

python backfill_isin.py [Optionen]

Parameter

ParameterStandardBedeutung
/limit:NalleMaximale Anzahl zu verarbeitender Ticker
/delay:ms500Wartezeit zwischen Anfragen in Millisekunden (Yahoo Rate-Limit)
/dryNeinNur anzeigen, was gefunden würde – nichts in DB schreiben
/log:LEVELINFOLog-Level: DEBUG · INFO · WARNING · ERROR

Typische Verwendung

  • Nach dem Import einer Broker-CSV mit neuen Tickern ohne ISIN
  • Nach seed_db.py, wenn ISINs für die Volltextsuche benötigt werden
# Erst testen:
python backfill_isin.py /dry /limit:20

# Dann ausführen:
python backfill_isin.py /limit:100 /delay:1000
Ticker, für die Yahoo Finance keine ISIN liefert (ETFs, Indizes), werden übersprungen und beim nächsten Lauf erneut versucht.
