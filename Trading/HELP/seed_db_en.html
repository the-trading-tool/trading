Initialise database seed_db.py

Creates the initial ticker database (yf_tickers.db) with predefined index members. A one-off setup step at the first installation.

Call

python seed_db.py
python seed_db.py --dry-run   # Only show what would be written

Included indices

IndexContent
DAX 4040 largest German companies (XETRA)
MDAX60 mid-cap German companies
SDAX70 smaller German companies
S&P 500500 largest US companies
Index instrumentsThe indices themselves (^GDAXI, ^MDAXI, ^SPX …)

Setup order (first installation)

  1. python seed_db.py – create the ticker DB
  2. python get_asset_info.py – load fundamentals
  3. python get_asset_data.py 1d:2y – load historical prices
  4. python asset_perf2.py – compute indicators
  5. streamlit run asset_analyzer.py – start the app
Existing entries in yf_tickers.db are not overwritten. For a complete reset, delete the file first.
Custom tickers can be added at any time after seeding via the admin panel.
