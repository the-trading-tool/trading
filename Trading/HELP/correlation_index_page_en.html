Correlation Index correlation_index_page.py

Shows the rolling correlation of daily log returns for five key macro pairs. This reveals whether asset classes are currently moving together (positive correlation) or in opposite directions (negative correlation) — a gauge for diversification and risk-on/risk-off regimes.

Observed pairs

PairReading when co-moving (+)
S&P 500 ↔ BitcoinBTC acts as a risk asset, little diversification
Bitcoin ↔ GoldBoth traded as a store of value ("digital gold")
S&P 500 ↔ US Dollar IndexUnusual — normally negative; positive = stress/regime signal
Copper ↔ S&P 500The economy confirms the equity move (risk-on)
US Treasuries (10Y) ↔ S&P 500Rate-driven; 60/40 diversification weakened

Usage

  • Window (30 / 90 days): length of the rolling correlation window in trading days. 30 days reacts faster, 90 days is more stable.
  • Overview table: current value (colour-coded), trend arrow (vs. ~1 month) and a classification per pair.
  • Per pair: a chart of both windows (the selected one emphasised, ±0.6 bands, zero line), key figures and an automatically generated interpretation.

Methodology – what is measured

AspectValue
MeasurePearson correlation of daily log returns ln(Cₜ/Cₜ₋₁) — not of price levels/trends
Range−1 (perfect opposite) … 0 (decoupled) … +1 (perfect co-movement)
Classification|r| ≥ 0.6 strong · ≥ 0.3 moderate · ≥ 0.15 weak · otherwise decoupled
Data sourcelocal daily prices (day_data) from the yf_<ticker>.db files
Comparisons with external tools/AI often differ when they look at price/trend paths instead of return correlations, or use a different time window or data snapshot. If the sign is reversed, first check whether the same instrument and method are meant.

Daily computation (scheduler)

The values are not computed live but written daily into correlation_index.db by the scheduler. Job command:

  • python recalc_correlation.py — recomputes all pairs (a wrapper around python -m tradinglib.correlation_index).
  • Recommended schedule: 22:35, Mon–Sat, after the price download and the performance simulation. On a fresh setup via install.ps1/install.sh the CORRELATION_INDEX job is created automatically.
  • If no correlation_index.db exists yet, the page offers a "Compute now" button as a fallback.
Prerequisite: the six instruments must be present as price DBs. seed_db.py adds them to the INDEX/CRYPTO/METALS/CURRENCIES/COMMODITIES groups, which are loaded by the YAHOO_*_DATA_GROUP//index jobs. Reachable via the Correlation Index menu entry (Market group) or via /?correlation=true.
