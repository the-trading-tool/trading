Multi-Strategies premium/multi_transaction.pyPremium

Manages and simulates several trading strategies in parallel, each with its own index universe, buy/sell conditions and budget. It forms the basis for the KPIs on the dashboard page and for automated trading.

Premium feature (Sidebar → Portfolio → Multi-Strategies), visible only to admin accounts with the license feature strategy_engine.

Structure of a strategy

Strategies are stored in config.db under the key multi_transactions as a nested structure:

  • Outer level: strategy name (e.g. "Value Trend Strategy", "Support/Resistance Strategy")
  • Inner level: index name (e.g. SPX, GDAXI, MDAXI) each with:
FieldMeaning
buyBuy condition as an expression over indicator columns, e.g. overallValueTrend > 65
sellSell condition, e.g. ewo < ewo_ema
num_assetsMaximum number of simultaneously held names for this index
investStarting capital for this index (in currency or the system currency)
currencySettlement currency; ANY = no conversion
order_bySort column for selecting the top names (e.g. sortino, overallValueTrend)

Usage

  • Data from: select the simulation year (current year or archive DBs asset_simulation_{year}.db)
  • Filter "buy/sell computation from date": limits the simulated trades to a period (default: last Friday)
  • Compute transactions: starts the simulation for all strategies × indices – may take a while depending on the data volume (progress bar)
  • Reset: discards the computed results again
  • Show transaction detail trend & data: shows a detail view per index with metrics, a trade table and a price chart
A name is bought only once globally: if an earlier strategy has already added a ticker to the portfolio, a new buy signal for the same ticker in a later strategy is ignored (prevents duplicate positions across strategies).

Analysis

  • Cumulative-gain chart per index: development of the cumulative profit across all simulated trades
  • Trade table with Excel export (📥 download trades/buys/sells)
  • Monthly performance heatmap (month × year, RdYlGn colour scale)
  • Strategy metrics: open positions, profit factor, hit rate, avg. profit/trade, realised profit, longest winning/losing streak, best/worst trades (3 months & 1 year)
  • Portfolio overlap warning: reports if the same ticker is held in several strategies at once
For strategies whose name contains "value trend", a ⚠️ geopolitics notice is additionally shown automatically.

Relationship to other pages

  • Dashboard: shows a summary of all strategies (starting capital, portfolio value, performance, max. positions)
  • Paper / Live Trading: strategies configured here can be selected there under "Enable strategies" for automatic order execution
  • asset_perf2.py calls run_notifier() after each run, which reports new buy/sell signals of these strategies via Pushover (see the "Signal notification" help)
