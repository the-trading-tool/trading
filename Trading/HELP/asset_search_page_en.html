Asset Search asset_search_page.py

Finds assets by full-text search across tickers and company names and opens the selected result directly in the Asset Viewer.

  • Search field: ticker (e.g. ^SPX, TLT) or part of a name (e.g. "Apple", "SAP"). Prefix search via FTS5.
  • Max results: limits the result list (5–100).
  • Open → per result jumps to the Asset Viewer (?asset=true&symbol=<ticker>).
Search reads asset_info_fts (FTS5 from asset_info.db). Newly imported tickers are searchable as soon as get_asset_info.py has run.
