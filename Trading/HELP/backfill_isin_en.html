ISIN backfill backfill_isin.py

Fills in missing ISINs in the ticker database (yf_tickers.db) by querying Yahoo Finance. Useful after importing new tickers without an ISIN.

Call

python backfill_isin.py [options]

Parameters

ParameterDefaultMeaning
/limit:NallMaximum number of tickers to process
/delay:ms500Wait time between requests in milliseconds (Yahoo rate limit)
/dryNoOnly show what would be found – write nothing to the DB
/log:LEVELINFOLog level: DEBUG · INFO · WARNING · ERROR

Typical use

  • After importing a broker CSV with new tickers without an ISIN
  • After seed_db.py, when ISINs are needed for the full-text search
# Test first:
python backfill_isin.py /dry /limit:20

# Then run:
python backfill_isin.py /limit:100 /delay:1000
Tickers for which Yahoo Finance provides no ISIN (ETFs, indices) are skipped and retried on the next run.
