Signal notification signal_notifier.py

Sends instant push notifications to your smartphone (via Pushover) as soon as a new buy or sell signal is detected.

Prerequisites

  1. Install the Pushover app on your smartphone (pushover.net)
  2. In the admin panel → API access: enter pushover_token (app token) and pushover_user (user key)

Message content

SignalContent of the Pushover message
BuyTicker · buy price · stop-loss · take-profit · short AI analysis
SellTicker · sell price · profit/loss in % and absolute

CLI call

python -m tradinglib.signal_notifier [/force] [/date:YYYY-MM-DD] [/user:admin]
ParameterMeaning
/forceResends already-sent signals too (ignores deduplication)
/date:YYYY-MM-DDChecks signals for a specific date instead of today
/user:nameUser context for multi-user setups (default: admin)

Deduplication

Already-sent signals are stored in pushover_notifier.json. No signal is sent twice, even if the script runs several times a day.

Automation

Best run automatically via the scheduler after each asset_perf2.py run:

python asset_perf2.py && python -m tradinglib.signal_notifier
The trading agent (run_agent.py) calls the notifier automatically with the --notify flag.
