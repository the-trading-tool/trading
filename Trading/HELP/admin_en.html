Admin panel admin.py

The app's central administration interface. Reachable via the Admin menu item (visible only to users with admin rights).

Tab 1 – Ticker management

  • Add new tickers manually or import them from a CSV file
  • Delete existing tickers or assign them to a different index
  • Maintain the ISIN mapping (yf_tickers.db)
  • Scalable import: read ISIN lists from broker exports

Tab 2 – SQLite editor

  • Direct SQL queries on all local databases
  • Select a database → enter SQL → show the result as a table
  • Write access: INSERT, UPDATE, DELETE possible
SQL commands are executed directly. Incorrect DELETE or UPDATE statements can irreversibly delete data.

Tab 3 – API access (KSP)

EntryUse
groqGroq API key for LLM analysis (llama-3.3-70b)
gapiGoogle Gemini API key
ollamaOllama URL + model name for local AI
pushover_token / pushover_userPushover credentials for push notifications
Broker keysAlpaca / IBKR / paper-trading credentials
Passwords are stored encrypted in config.db. Leave the field empty = keep the existing password.

Banner AI analysis

In the admin panel there is a Banner Note / AI analysis expander with:

  • Provider selection for the analysis
  • Debug mode: shows all collected input data without an API call
  • Button Start analysis: immediately generates a new AI tip
