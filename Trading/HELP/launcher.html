Anwendung starten launcher.py · asset_analyzer.py

Die Trading App ist eine Streamlit-Webanwendung, die lokal im Browser läuft. Es gibt zwei Wege, sie zu starten.

Weg 1 – Direkt per Kommandozeile (empfohlen für Entwicklung)

cd Trading
streamlit run asset_analyzer.py

Der Browser öffnet sich automatisch unter http://localhost:8080.

Weg 2 – Windows-Launcher (für Endanwender)

python launcher.py

Der Launcher:

  1. Erkennt die Python-Installation automatisch
  2. Startet streamlit run asset_analyzer.py im Hintergrund
  3. Wartet, bis der Server bereit ist
  4. Öffnet den Browser automatisch
  5. Zeigt optional ein System-Tray-Icon

Als Windows-EXE kompilieren

pyinstaller --onefile launcher.py

Die erzeugte launcher.exe kann direkt per Doppelklick gestartet werden, ohne Python-Kenntnisse.

URL-Parameter

ParameterBeispielWirkung
symbol/?symbol=AAPLAsset Details für diesen Ticker direkt öffnen
rotation/?rotation=trueSektorrotations-Dashboard öffnen
Port und weitere Streamlit-Einstellungen können in .streamlit/config.toml angepasst werden (z. B. server.port = 8080).
