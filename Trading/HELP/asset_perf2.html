Performance-Simulation asset_perf2.py

Das zentrale CLI-Skript der App. Berechnet technische Indikatoren auf historischen OHLC-Daten und schreibt Scores sowie Kauf-/Verkaufssignale in die lokale Simulationsdatenbank.

Vollständiger Lauf (Standard)

python asset_perf2.py

Verarbeitet alle Ticker mit dem Standard-Intervall (1d:1mo) und schreibt Ergebnisse in asset_simulation_.db.

Intervall und Zeitraum angeben

python asset_perf2.py 1h:6mo
python asset_perf2.py 1d:1y 1wk:2y

Filter-Parameter

ParameterWirkung
/select:AAPL,MSFTNur diese Ticker verarbeiten
/index-member:SPXNur Ticker eines bestimmten Index
/index-onlyNur Index-Instrumente selbst (kein Einzeltitel)
/allAlle Ticker unabhängig vom Index
/year:2024Berechnung auf ein Kalenderjahr beschränken
/inverseBearbeitungsreihenfolge umkehren

Fast-Modes (ohne Neuberechnung)

ModusBeispielBeschreibung
backfillpython asset_perf2.py /backfill:heikin,macd,rsiFehlende Indikator-Spalten aus vorhandenen OHLCV-Daten nachfüllen – kein Internet nötig
rescorepython asset_perf2.py /rescoreOVT-Scores neu berechnen ohne OHLCV-Download – verwendet gespeicherte DB-Spalten

Bekannte Backfill-Indikatoren

heikin  → ha_close, ha_open, ha_ema_high, ha_ema_low
macd    → macd, macd_diff, macd_signal
rsi     → rsi, rsi_ema, rsi_momentum
ewo     → ewo, ewo_ema, ewo_diff, ewo_angle
adx     → adx, adx_plus_di, adx_minus_di
markov  → markov_regime
dema    → dema_ema_fast, dema_ema_slow, dema_buy, dema_sell
relvol  → relvol_ratio
Täglicher Cron-Empfehlung: nach Börsenschluss automatisch ausführen, damit die App immer aktuelle Signale zeigt.
Ein vollständiger Lauf kann je nach Tickeranzahl mehrere Minuten dauern. /rescore ist deutlich schneller.
