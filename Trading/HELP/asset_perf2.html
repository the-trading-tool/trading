Performance-Simulation asset_perf2.py

Das zentrale CLI-Skript der App. Berechnet technische Indikatoren auf historischen OHLC-Daten und schreibt Scores sowie Kauf-/Verkaufssignale in die lokale Simulationsdatenbank.

Vollständiger Lauf (Standard)

python asset_perf2.py

Verarbeitet ohne Filter genau die Mitglieder echter Börsen-Indizes (Gruppen mit ^-Präfix wie ^GDAXI/^SPX) mit dem Standard-Intervall (1d:1mo) und schreibt Ergebnisse in asset_simulation_.db. Kategorie-Gruppen (ETP, COMMODITIES, CRYPTO …) sind nicht enthalten – diese laufen über /group:NAME in eigenen Durchläufen.

Intervall und Zeitraum angeben

python asset_perf2.py 1h:6mo
python asset_perf2.py 1d:1y 1wk:2y

Filter-Parameter (Ticker-Auswahl)

ParameterWirkung
(ohne Filter)Nur Mitglieder echter Börsen-Indizes (Gruppen mit ^-Präfix).
/group:ETPNur Mitglieder der genannten Gruppe(n); mehrere kommagetrennt, z.B. /group:METALS,COMMODITIES. Für eigene Läufe von ETP, CRYPTO, CURRENCIES usw.
/inverseNur Ticker, die keiner Gruppe zugeordnet sind (Einzeltitel ohne Index-/Gruppen-Verknüpfung).
/allAlle Stocks und Indizes außer ETP-Gruppe; schreibt nach asset_simulation_all.db.
/all /group:ETPNur ETP-Mitglieder; schreibt nach asset_simulation_etp.db. Läuft unabhängig von /all – eigener teurer Berechnungslauf.
/year:2024Berechnung auf ein Kalenderjahr beschränken (Snapshot/Backtest).
/worker:NN parallele Prozesse (ProcessPoolExecutor, CPU-lastig). Auf Windows ohne Angabe automatisch begrenzt (RAM pro Prozess).

Fast-Modes (ohne Neuberechnung)

ModusBeispielBeschreibung
backfillpython asset_perf2.py /backfill:heikin,macd,rsiFehlende Indikator-Spalten aus vorhandenen OHLCV-Daten nachfüllen – kein Internet nötig
rescorepython asset_perf2.py /rescoreOVT-Scores neu berechnen ohne OHLCV-Download – verwendet gespeicherte DB-Spalten

Bekannte Backfill-Indikatoren

heikin  → ha_close, ha_open, ha_ema_high, ha_ema_low
markov  → markov_regime   (zusätzlich markov_regime_wk / _mo auf Wochen-/Monatsbasis)
macd    → macd, macd_diff, macd_signal, macd_trend
rsi     → rsi, rsi_ema, momentum
ewo     → ewo, ewo_ema, ewo_diff, ewo_angle, ewo_trend
adx     → adx, adx_plus, adx_minus, adx_angle
dema    → dema_ema_fast, dema_ema_slow, dema_buy, dema_sell
hor     → hor_val, hor_threshold
sup     → sup_support, sup_resistance
relvol  → relvol_ratio
atc     → atc_top_high, atc_bot_low
scr     → scr_1mo, scr_3mo, scr_eoy, scr_buy, scr_sell
Täglicher Cron-Empfehlung: nach Börsenschluss automatisch ausführen, damit die App immer aktuelle Signale zeigt.
Ein vollständiger Lauf kann je nach Tickeranzahl mehrere Minuten dauern. /rescore ist deutlich schneller.
