⚙ Settings system_config.py

The settings dialog opens via the ⚙ button in the sidebar and is organized into tabs. All values are stored per user in config.db and loaded automatically on the next app start. The Admin tab is only shown to admin users.

General

Charts & Indicators

These values define what is preset when the Asset Viewer is first loaded. They can be overridden per session at any time via the selectors at the top of the chart.

SettingDescriptionPossible values
Default overlay Comma-separated list of indicator short names placed on the price on first load. heikin, sup, bos · candle, gan · …
Default oscillator Comma-separated list of indicators shown as sub-charts on first load. ewo, adx, macd · …
Show details tab Shows an additional "Details" tab with extended metrics on the main page. Helpful for detailed analysis, but a wide screen is recommended. True · False
Show Pine Script export Shows the button below the chart to export the current indicator configuration as Pine Script v5 (TradingView). True · False
Show regime / market-stress banner show_regime Shows the early-warning banner about the market breadth of the associated index below the chart in the Asset Viewer (bull/bear/sideways change + divergence). Off by default, because the initial computation of large indices (e.g. ^RUT with ~1900 members) takes time; the result is then cached per day (see warm_market_stress.py). True · False (default False)
Mark non-trading times in bands mark_nontrading_times True: filled bands (Bollinger, Heikin EMA, G-FRAMA, DEMA, Ichimoku) break over weekends/bank holidays — the gaps mark non-trading times. False: continuous fill (smoother); for assets that trade on otherwise-closed days (e.g. futures) the fill can be imprecise at transitions. True · False

Strategies & Trading

Strategy configuration

SettingDescription
Transactions JSON configuration of the trading strategies. Outer keys = strategy name, inner keys = index name, value = maximum number of simultaneous positions in that index.
Read by the banner page, Multi-Strategies and the trading agent.

Example transaction JSON:

{"Value Trend Strategy": {"^GDAXI": 3, "^SPX": 3}, "Support Strategy": {"^GDAXI": 2}}

Buy and sell conditions

These expressions control which candles are marked as a buy or sell signal in the performance simulation (asset_perf2.py) and in the Asset Viewer.

SettingDescription
Buy condition Python-like boolean expression over DataFrame columns. Every candle for which the expression is True is marked as a buy signal (green ▲ in the chart).
Sell condition Analogous expression for the sell signal (red ▼ in the chart).

Available columns correspond to the computed indicators, e.g.:

(ha_close > ha_open) & (Close > ha_ema_high) & (macd > macd_signal) & (rsi > 50) & (markov_regime < 2)
Only use column names that are actually computed for the chosen interval/period. Unknown columns lead to a silent error (no signal).

Other

SettingDescription
Tradable only (ISIN required) require_isin Restricts the selection in Strategy Finder and Multi-Transactions to names with a valid ISIN (an approximation for "tradable at the broker"). Only sensible after a full backfill_isin.py run, otherwise names that are merely not yet resolved get filtered out too. Overridable per strategy/index via the require_isin field in the transaction JSON.
Trailing stop enabled trailing_stop_enabled Enables the trailing-stop logic for live/paper trading positions opened by the trading agent.

Admin (admin users only)

License

Shows license tier, licensee, expiry date and active features. "Reload license" reads license.json without an app restart.

Data provider

SettingDescription
Data provider Source for price data: Yahoo Finance (free, default) or FMP (Financial Modeling Prep, requires an API key in the KSP entry fmp). Includes ticker override mapping and a connection test when FMP is selected.

Logging

SettingDescription
Logging Enables output of debug messages to the console and log file.
Log file name Path/name of the log file, relative to the app directory. Default: logfile.txt.
Log level Minimum severity for logged messages: DEBUG > INFO > WARNING > ERROR > CRITICAL.

The Admin panel's Log viewer (System tab) reads directly from whichever file handler is attached here — enable logging first if you want to inspect log output there.

Advanced / Performance

SettingDescription
S/R scaling Scaling factor for support/resistance calculations. Higher values produce wider S/R zones; default value 100.
Real-time prices Enables automatic price refresh in the live ticker. Increases the Yahoo API load — leave at False with many assets.
OVT smoothing Smoothing period for the Overall Value Trend indicator (OVT). Values 1–5; higher values reduce noise but delay signals.
All changes are only written permanently to config.db after clicking Save. A reload without saving discards the inputs.
