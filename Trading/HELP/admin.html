Admin-Panel admin.py

Zentrale Verwaltungsoberfläche der App. Erreichbar über den Menüpunkt Admin (nur für Benutzer mit Admin-Rechten sichtbar).

Tab 1 – Ticker-Verwaltung

  • Neue Ticker manuell hinzufügen oder aus einer CSV-Datei importieren
  • Bestehende Ticker löschen oder einem anderen Index zuordnen
  • ISIN-Mapping pflegen (yf_tickers.db)
  • Skalierter Import: ISIN-Listen aus Broker-Exporten einlesen

Tab 2 – SQLite-Editor

  • Direkte SQL-Abfragen auf alle lokalen Datenbanken
  • Datenbank auswählen → SQL eingeben → Ergebnis als Tabelle anzeigen
  • Schreibzugriff: INSERT, UPDATE, DELETE möglich
SQL-Befehle werden direkt ausgeführt. Falsche DELETE- oder UPDATE-Statements können Daten unwiderruflich löschen.

Tab 3 – API-Zugänge (KSP)

EintragVerwendung
groqGroq-API-Key für LLM-Analyse (llama-3.3-70b)
gapiGoogle Gemini API-Key
ollamaOllama-URL + Modellname für lokale KI
pushover_token / pushover_userPushover-Zugangsdaten für Push-Benachrichtigungen
Broker-KeysAlpaca / IBKR / paper-trading Zugangsdaten
Passwörter werden verschlüsselt in config.db gespeichert. Das Feld leer lassen = vorhandenes Passwort beibehalten.

Banner-KI-Analyse

Im Admin-Panel gibt es einen Expander Banner Note / KI-Analyse mit:

  • Provider-Auswahl für die Analyse
  • Debug-Modus: zeigt alle gesammelten Eingabedaten ohne API-Call
  • Button Analyse starten: generiert sofort einen neuen KI-Tipp
