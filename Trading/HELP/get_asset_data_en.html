Data fetch get_asset_data.py

Downloads historical OHLCV price data (Open, High, Low, Close, Volume) from Yahoo Finance and stores it locally in per-ticker SQLite databases (yf_{TICKER}.db).

Call

python get_asset_data.py [interval:period] [filter]

Interval / period

ExampleMeaning
1d:1yDaily candles, last year
1h:6moHourly candles, last 6 months
5m:2d5-minute candles, last 2 days
1wk:5yWeekly candles, last 5 years

Several combinations at once are possible: python get_asset_data.py 1d:1y 1h:6mo

Filter parameters (ticker selection)

Without a filter the ticker list is imported from All_Assets.xlsx (new groups and links are created in the process) and then downloaded.

ParameterEffect
/index_memberOnly members of real stock indices. These are exactly the groups whose name starts with ^ (^GDAXI, ^MDAXI, ^SPX, …). Category groups are not included here.
/group:ETPOnly members of the named group(s) from the indices table. Several comma-separated: /group:METALS,COMMODITIES. Case-insensitive. This fetches ETP, CRYPTO, CURRENCIES etc. specifically in their own runs.
/inverseOnly tickers assigned to no group (single names without index/group link).
/allAll known tickers (every group + ungrouped).
/indexOnly the non-stock groups (INDEX, COMMODITIES, METALS, CURRENCIES, CRYPTO) plus currency pairs (…=X).

Parallel downloads

ParameterEffect
/worker:NN parallel download threads (default 1 = sequential). Recommendation 2–4 – more strains the Yahoo rate limit (HTTP 429). Each ticker writes to its own yf_{TICKER}.db, so there are no collisions.

Stored tables per database

  • min_data – minute/intraday candles
  • h60_data – hourly candles
  • day_data – daily candles
  • week_data – weekly candles
  • month_data – monthly candles
Existing data is updated incrementally – only new candles are downloaded. Existing entries are preserved.

Pipeline – making assets visible after import

This script only fills yf_tickers.db (groups/tickers) and the price DBs yf_{TICKER}.db. To make newly imported assets fully usable in the app, further steps are needed:

#ScriptFillsMakes visible
1get_asset_data.py (this script)yf_tickers.db, yf_{TICKER}.dbmarket in "Select by market" + price data
2get_asset_info.py /group:NAMEasset_info.db"Select company" dropdown + full-text search
3asset_perf2.py /group:NAME or /all /group:NAMEasset_simulation_.db (yearly DB) or asset_simulation_{name}.db (own DB)indicator overlays, buy/sell signals, metrics

Example for a new group (e.g. ETP), step by step:

python get_asset_data.py 1d:1y /group:ETP /worker:3
python get_asset_info.py /group:ETP /worker:4
python asset_perf2.py /all /group:ETP /worker:2

Note: /all /group:ETP writes to the dedicated database asset_simulation_etp.db (separate universe, visible under → ETP Assets). Without /all it would write to the year-based asset_simulation_.db.
