Edge Scores: COT-Scorecard cot_page.py

Die COT-Scorecard (Markt → Edge Scores, Untermenü links) zeigt, wie die großen Spekulanten (Fonds, CTAs – in der CFTC-Statistik „Non-Commercials“) in Währungen, Rohstoffen, Aktienindizes, Anleihen und Bitcoin positioniert sind, und verdichtet das zu einem Score von −3 bis +3 je Markt sowie einem Bias je Forex-Paar.

Datenquelle

  • CFTC Commitments of Traders, Datensatz „Legacy – Futures only“, über die kostenlose CFTC Public Reporting API (kein API-Key).
  • Stichtag ist jeweils Dienstag, veröffentlicht wird am Freitag darauf.
  • Die Seite lädt beim Öffnen automatisch nach, sobald ein neuer Report fällig ist. Manuell: Button Aktualisieren oder per CLI/Scheduler python -m tradinglib.cot_data (/full = komplette Historie).
  • Speicherort: database/cot.db, Historie ab 2018.

Score je Markt

KomponenteRegelPunkte
PositionierungLong-Anteil = Long / (Long + Short) der Non-Commercials, gemessen als Rang in den letzten 3 Jahren dieses Marktes (Spalte „Rang 3J“, 0 = tiefster, 100 = höchster Wert): ≥ 80 / ≥ 60 / ≤ 40 / ≤ 20+2 / +1 / −1 / −2
DynamikVeränderung des Long-Anteils zur Vorwoche: > +1 Pp / < −1 Pp+1 / −1

Warum relativ? In Gold und Silber sind Spekulanten fast immer mehrheitlich long (Silber 2018–2026 im Median 69 %), im Yen meist short. Feste Schwellen wie „≥ 60 % long = bullish“ bewerteten solche Märkte fast immer gleich – auch während die Spekulanten abbauten (Silber 11/2026). Der Rang zeigt, ob die Positionierung für diesen Markt gerade hoch oder niedrig ist.

COT-Index (nicht im Score): Lage der Netto-Position zwischen Minimum und Maximum der letzten 52 Wochen (0–100). ≥ 90 bzw. ≤ 10 wird als überfüllt markiert.
