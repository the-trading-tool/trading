Performance simulation asset_perf2.py

The app's central CLI script. Computes technical indicators on historical OHLC data and writes scores as well as buy/sell signals into the local simulation database.

Full run (default)

python asset_perf2.py

Without filters it processes exactly the members of real stock indices (groups with the ^ prefix such as ^GDAXI/^SPX) with the default interval (1d:1mo) and writes results to asset_simulation_.db. Category groups (ETP, COMMODITIES, CRYPTO …) are not included – those run via /group:NAME in their own passes.

Specifying interval and period

python asset_perf2.py 1h:6mo
python asset_perf2.py 1d:1y 1wk:2y

Filter parameters (ticker selection)

ParameterEffect
(no filter)Only members of real stock indices (groups with the ^ prefix).
/index:^SPXOnly the named indices; several comma-separated, e.g. /index:^DJI,^SPX,^RUT (case-insensitive).
/group:ETPOnly members of the named group(s); several comma-separated, e.g. /group:METALS,COMMODITIES. For separate runs of ETP, CRYPTO, CURRENCIES etc.
/inverseOnly tickers assigned to no group (single names without index/group link).
/allAll stocks and indices except the ETP group; writes to asset_simulation_all.db.
/all /group:ETPOnly ETP members; writes to asset_simulation_etp.db. Runs independently of /all – its own expensive computation pass.
/year:2024Restrict the computation to one calendar year (snapshot/backtest).
/worker:NN parallel processes (ProcessPoolExecutor, CPU-heavy). On Windows automatically limited when unspecified (RAM per process).

Fast modes (without recomputation)

ModeExampleDescription
backfillpython asset_perf2.py /backfill:heikin,macd,rsiFill in missing indicator columns from existing OHLCV data – no internet needed
rescorepython asset_perf2.py /rescoreRecompute OVT scores without an OHLCV download – uses stored DB columns

Known backfill indicators

heikin  → ha_close, ha_open, ha_ema_high, ha_ema_low
markov  → markov_regime   (additionally markov_regime_wk / _mo on a weekly/monthly basis)
macd    → macd, macd_diff, macd_signal, macd_trend
rsi     → rsi, rsi_ema, momentum
ewo     → ewo, ewo_ema, ewo_diff, ewo_angle, ewo_trend
adx     → adx, adx_plus, adx_minus, adx_angle
dema    → dema_ema_fast, dema_ema_slow, dema_buy, dema_sell
hor     → hor_val, hor_threshold
sup     → sup_support, sup_resistance
relvol  → relvol_ratio
atc     → atc_top_high, atc_bot_low
scr     → scr_1mo, scr_3mo, scr_eoy, scr_buy, scr_sell
Daily cron recommendation: run automatically after market close so the app always shows current signals.
A full run can take several minutes depending on the number of tickers. /rescore is significantly faster.
