Trading agent run_agent.py

Automated trading agent for paper and live trading. Evaluates buy/sell signals from asset_simulation_.db and sends broker orders.

Call

python run_agent.py [options]

Parameters

ParameterDefaultMeaning
--executeNoActually send orders (without this flag: dry run)
--useradminUser context (multi-user setup)
--regionallCheck signals of a specific index only (e.g. GDAXI)
--buy-offset0.0Percentage surcharge on the buy price (limit-order buffer)
--force-buyNoForce a buy even without a fresh signal
--notifyNoSend a Pushover notification after the run
--modepaperpaper or live
--brokeralpacaBroker backend: alpaca · ibkr

Exit codes

CodeMeaning
0No signal, all OK
1A buy or sell order was triggered
2Error (broker unreachable, database error …)

Recommended scheduler entry

# Every 15 minutes during trading hours:
python run_agent.py --notify --mode paper
With --execute --mode live real orders are placed at the broker. Test sufficiently in paper mode before enabling live trading.
The batch file run_agent.bat is a Windows wrapper for the same call.
