Signal-Benachrichtigung signal_notifier.py

Sendet sofortige Push-Benachrichtigungen auf das Smartphone (via Pushover), sobald ein neues Kauf- oder Verkaufssignal erkannt wird.

Voraussetzungen

  1. Pushover-App auf dem Smartphone installieren (pushover.net)
  2. Im Admin-Panel → API-Zugänge: pushover_token (App-Token) und pushover_user (User-Key) eintragen

Nachrichteninhalt

SignalInhalt der Pushover-Nachricht
KaufTicker · Kaufpreis · Stop-Loss · Take-Profit · KI-Kurzanalyse
VerkaufTicker · Verkaufspreis · Gewinn/Verlust in % und absolut

CLI-Aufruf

python -m tradinglib.signal_notifier [/force] [/date:YYYY-MM-DD] [/user:admin]
ParameterBedeutung
/forceSendet auch bereits gesendete Signale erneut (ignoriert Deduplizierung)
/date:YYYY-MM-DDPrüft Signale für ein bestimmtes Datum statt heute
/user:nameBenutzer-Kontext für Multi-User-Setups (Standard: admin)

Deduplizierung

Bereits versendete Signale werden in pushover_notifier.json gespeichert. Kein Signal wird doppelt verschickt, auch wenn das Skript mehrfach täglich läuft.

Automatisierung

Am besten per Scheduler nach jedem asset_perf2.py-Lauf automatisch ausführen:

python asset_perf2.py && python -m tradinglib.signal_notifier
Der Trading-Agent (run_agent.py) ruft den Notifier mit --notify-Flag automatisch auf.
