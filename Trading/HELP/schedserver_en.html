Scheduler daemon schedserver.py

A background process that runs recurring jobs automatically – e.g. the daily data download, indicator computation and trading-agent runs.

Starting

python schedserver.py

The process runs continuously in the background and checks every minute whether a job is due.

Managing jobs

Jobs are configured directly in the app via the admin panel:

  • Admin → Scheduler tab (if enabled)
  • Jobs are stored in scheduler.db
  • Supported schedules: daily (HH:MM), hourly, every N minutes

Typical job configuration

TimeCommandPurpose
22:00python get_asset_data.py 1d:1yUpdate daily prices
22:30python asset_perf2.pyRecompute indicators
22:45python -m tradinglib.signal_notifierNotify buy/sell signals
every 15 minpython run_agent.py --notifyTrading agent (trading hours)
every 15 minpython check_stoploss.py --notifyStop-loss monitoring

Parallel execution

At most 4 jobs run at the same time. Additional jobs are queued.

The scheduler runs as a simple Python process – not a systemd/Windows service. After a machine restart it must be started again manually (or set up as an autostart).
Logs are written to the console and optionally to a file. For production use, a Windows service or Task Scheduler entry is recommended.
