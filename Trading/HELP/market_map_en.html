Market Map market_map.py

A visual heatmap of all monitored securities. Tile colour and size encode performance and trading volume at a glance.

Colour coding

ColourMeaning
GreenPositive price move over the selected period
RedNegative price move
GreyNo or neutral change / missing data

Tile size

The size of each tile reflects the asset's overallValueTrend (OVT) score: the higher the score, the larger the tile.

Interaction

  • Click a tile → opens the Asset Details page for that security
  • Hover → shows ticker, name and current OVT value as a tooltip

Controls

SettingEffect
Index filterRestricts the view to a specific stock index (SPX, GDAXI …)
PeriodPrice change over 1 day, 1 week or 1 month
SortingBy OVT score, price change or alphabetically
The data comes from the local database (asset_simulation_.db). Run asset_perf2.py first for up-to-date values.
