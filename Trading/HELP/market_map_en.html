Market Map market_map.py

A visual heatmap of all monitored securities. Tile colour and size encode performance and trading volume at a glance.

Colour coding

ColourMeaning
GreenPositive price move over the selected period
RedNegative price move
GreyNo or neutral change / missing data

Tile size

The size of each tile follows the selected metric (market cap, debt or revenue).

Interaction

  • Click a tile → opens the Asset Details page for that security
  • Hover → shows ticker, name and current value as a tooltip

Controls

SettingEffect
Index filterRestricts the view to a specific stock index (SPX, GDAXI …)
PeriodPrice change over 1 day, 1 week or 1 month
SortingBy price change or alphabetically

Portfolios

With View the map shows your own holdings instead of an index (only with access to the respective portfolio page):

ViewSource
Own transactionsOpen positions from trades.db (Scalable import, manual entry), valued at the latest close
Paper accountCurrent positions of the paper broker (Trading page)
Multi StrategiesOpen positions of the current Multi Strategies year (trades{year}.db)
  • Tile size: position value (shares × price) or market cap, both converted to the system currency
  • Colour: additionally since buy % (default); the other metrics as in the index view
  • Group by: sector or strategy (when the source knows strategies). By sector, a security held by two strategies becomes one tile.
  • Positions are loaded once per session; 🔄 Reload fetches them again.
The data comes from the local database (asset_simulation_.db). Run asset_perf2.py first for up-to-date values.
