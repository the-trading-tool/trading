Paper / Live Trading premium/trading_page.pyPremium

Executes buy/sell signals of the enabled strategies directly at a connected broker – either as Paper Trading (simulation with virtual capital) or as Live Trading with real money.

This page is a Premium feature and only visible to admin accounts if a valid license with the feature paper_trading is present (Sidebar → Portfolio → Paper / Live Trading). Without a license the message "Trading not available – please check your license" appears.

The buttons at the top of the page switch between ● Paper Trading – Alpaca and ○ Live Trading – IBKR. The currently selected broker is highlighted.

⚠ Live mode: As soon as IBKR is selected and ibkr_port is configured to 7496, orders are executed with real money. The page then shows a red warning at the top.

Registration

  • Alpaca: create a free account at alpaca.markets, generate a Paper key (Key ID + Secret) in the dashboard under "API Keys" and store it as a KSP entry – username = Key ID, password = Secret. Set the name of the KSP entry under ⚙ Settings → alpaca_ksp_name (default: av-paper)
  • IBKR: open a securities account at Interactive Brokers, install/start TWS or IB Gateway locally and enable API access (port 7497 = paper, 7496 = live). Enter host/port under ⚙ Settings – no additional API key is needed
A detailed step-by-step guide and recommendations for recurring background jobs (scheduler) can be found in the "Setup & Scheduler" help.

Test mode (dry run)

The 🧪 Test mode switch simulates order execution without actually sending orders to the broker – ideal for checking strategy signals before going live. Corresponds to the configuration trading_agent_dry_run, which is also used by the CLI trading agent (run_agent.py).

Tabs

📊 Account

  • Connection status to the selected broker (🟢 connected / 🔴 not connected)
  • Portfolio performance chart over a selectable period
  • Allocation chart of the current positions
  • Enable strategies: choose which strategies from multi_transactions are considered for automatic trading (stored in trading_enabled_strategies)

🔔 Signals

  • 🔄 Recompute signals: restarts the portfolio simulation for all enabled strategies (timestamp of the last computation is shown)
  • Display of current 🟢 buy signals and 🔴 sell signals per strategy/index/ticker
  • ATR multiplier for computing the stop-loss per signal
  • Filter: All / Buys only / Sells only; closed positions of the last N days can be shown
  • Select signals via checkbox and send them to the broker via "Execute N selected order(s)" – incl. a confirmation dialog with an overview of all order details
  • In test mode the note "Order(s) would be sent" is shown instead of a real order
  • Non-tradable signals (no broker symbol for the ticker at the selected broker) are skipped automatically

📂 Positions

  • Overview of all currently open positions at the selected broker (ticker, quantity, cost basis, current price, profit/loss)

📋 History

  • Previous order and execution history of the broker

📈 Comparison

  • Comparison of the live/paper performance with the simulated strategy performance (target/actual reconciliation)

⚙ Settings

  • Manage broker credentials or test the connection manually
  • Connection parameters such as ibkr_host / ibkr_port

Automation

The CLI trading agent run_agent.py uses the same broker connection and can execute signals unattended (e.g. via the scheduler) – see the help for Trading agent (run_agent.py) in the "CLI scripts" tab.
