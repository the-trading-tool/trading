Performance performance_details.py

Shows the currently computed valuation and performance metrics of all tickers from asset_simulation_.db, sorted by overallValueTrend and sortino – the fastest overview of which names the model currently rates best.

Usage

  • A table of all names with the key indicator columns (OVT, RSI, trend direction, analyst price targets, sector, Sortino/Sharpe …)
  • Clicking a row opens a mini chart of the selected name
  • 📥 Download dataset: Excel export of the full table
  • Show chart grid: additionally shows a grid of mini charts of the top-rated names (count selectable: 5/10/20)
The data source is the central DuckDB engine, which can merge several asset_simulation_*.db files. Results are cached for 5 minutes (@st.cache_data(ttl=300)) – so a new run of asset_perf2.py becomes visible with a slight delay.

Asset overview (Admin)

Admin accounts additionally see the sub-item → All Assets (sidebar under Assets & Performance). This view corresponds to all_assets.py and allows free filtering via custom buy/sell queries – see the "Asset overview" help.
