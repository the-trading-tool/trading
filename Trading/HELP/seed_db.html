Datenbank initialisieren seed_db.py

Erstellt die initiale Ticker-Datenbank (yf_tickers.db) mit vordefinierten Indexmitgliedern. Einmaliger Setup-Schritt bei der ersten Installation.

Aufruf

python seed_db.py
python seed_db.py --dry-run   # Nur anzeigen, was geschrieben würde

Enthaltene Indizes

IndexInhalt
DAX 4040 größte deutsche Unternehmen (XETRA)
MDAX60 mittelgroße deutsche Unternehmen
SDAX70 kleinere deutsche Unternehmen
S&P 500500 größte US-amerikanische Unternehmen
Index-InstrumenteDie Indizes selbst (^GDAXI, ^MDAXI, ^SPX …)

Setup-Reihenfolge (Erstinstallation)

  1. python seed_db.py – Ticker-DB anlegen
  2. python get_asset_info.py – Fundamentaldaten laden
  3. python get_asset_data.py 1d:2y – Historische Kurse laden
  4. python asset_perf2.py – Indikatoren berechnen
  5. streamlit run asset_analyzer.py – App starten
Bereits vorhandene Einträge in yf_tickers.db werden nicht überschrieben. Für einen kompletten Reset die Datei vorher löschen.
Eigene Ticker können nach dem Seeding jederzeit über das Admin-Panel hinzugefügt werden.
