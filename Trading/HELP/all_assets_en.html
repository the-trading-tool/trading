Asset overview all_assets.py

A screener for all tickers in the local database: a filterable table with the current indicator values, optionally supplemented by a mini-chart grid of the top names. For admin accounts, available under Assets & Performance in two variants:

  • → All Assets – stocks and indices from asset_simulation_all.db (excluding the ETP group)
  • → ETP Assets – only the ETP group from asset_simulation_etp.db (separate computation run via asset_perf2.py /all /group:ETP)

Usage

ElementEffect
Filter input field (top)Free-text query used to filter the result table – the default is the global buy query from the system settings
Click a table rowOpens a mini chart of the selected name with a link to the full Asset Details page
📥 Download datasetExcel export of the filtered table
Show chart gridAdditionally shows a grid of mini charts (count selectable: 5/10/20), sorted by Sortino ratio

Sorting & content

The table shows the most recent dataset (Date DESC) per ticker from the respective database (asset_simulation_all.db or asset_simulation_etp.db), sorted by currency, Sortino ratio and overallValueTrend. All computed indicator columns are included.

Filter syntax

The filter field accepts pandas-/SQL-compatible conditions on the indicator columns, e.g.:

  • overallValueTrend > 65
  • (rsi > 20) AND (rsi < 80) AND (ewo > ewo_ema)
  • macd_diff > 0
Available column names are all computed indicators from asset_simulation_all.db. The default buy/sell queries are set in the configuration dialog (🏵) under System settings.
